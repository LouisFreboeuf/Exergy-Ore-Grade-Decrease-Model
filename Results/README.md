# Results Directory

This directory contains output files from the Exergy Ore Grade Decrease Model calculations.

## Subdirectories

- **EsElec**: Results for EsElec scenario
- **FrElec**: Results for FrElec scenario  
- **manual4CuCathode**: Manual calculations for copper cathode flows

## File Types

- **IS4CF1.csv**: Impact scores using Characterization Factor 1
- **IS4CF1_2.csv**: Alternative impact scores using CF1 variant

## Notes

- Results are generated by running the `SurplusEx.ipynb` notebook
- CSV files contain impact scores for various flows
- Files can be regenerated by re-running the notebook
